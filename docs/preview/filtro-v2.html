Filtro v2

Maquete · aguardando aprovação

A tela nova do filtro, na escala do jogo e com a paleta do mod. Tudo aqui funciona: troque as abas, clique num item do inventário para pegá-lo e clique com ele no slot do inspetor, marque tags, monte uma regra e arraste a alça do canto para redimensionar (a janela fica centralizada). Números de itens por tag são ilustrativos.

# tag@ mod◆ regra Shift + clique no inventário: adiciona o item exatoClique: pega o item (para o inspetor)

Lista de entradas

  • Uma linha por entrada, com ícone, nome, tipo e estoque. A busca acha por nome, #tag ou @mod.
  • Continua sem limite prático (4.096 entradas), lista branca ou negra, e componentes como hoje.
  • A janela cresce como a do Baú: mais largura alonga os nomes, mais altura mostra mais linhas e mais tags.

Tags

  • Inspetor: clique no slot com um item no cursor (ou arraste do JEI, ou selecione um item na lista). Aparecem todas as tags dele para marcar.
  • Busca: digite parte do nome para ver todas as tags do jogo com quantos itens cada uma pega.
  • Prévia: passe o mouse numa tag para ver os itens dela na faixa de baixo.

Regras

  • Cada condição tem — / Sim / Não; a regra pega o item que cumpre todas as marcadas.
  • Só em limita a uma tag ou mod: Encantado + #c:armors = só armadura encantada.
  • O inventário acende o que a regra pega, antes de adicionar. Regra aceita estoque como qualquer entrada.
  • Livro encantado conta como Encantado; para separar, use Só em ou a lista negra.
