# Filter Card

<ItemImage id="wirelessautomate:filter_card" scale="2" float="left" />

A full filter in an item, to reuse on many faces. Each face has two card slots per type (items and
fluids), on the router screen.

<br clear="all" />

- **Edit:** right-click the air with the card.
- **Type:** with the card empty, Shift + right-click the air switches between items and fluids.
- **Copy from/to a face:** on the face's filter screen, under **More**, export the filter to the
  card or import from the card.
- **Duplicate:** a configured card + blank cards in a crafting table give identical copies (the
  original comes back).

<RecipeFor id="wirelessautomate:filter_card" />

Chemicals only use the face's built-in filter (there is no chemical card).
