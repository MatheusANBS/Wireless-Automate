# Wireless Automate

<ItemImage id="wirelessautomate:router" scale="2" float="left" />

**Wireless** transport of items, fluids, energy and Mekanism chemicals. Attach a
<ItemLink id="wirelessautomate:router" /> to each machine, choose what each machine face does
(extract, insert, storage) and every router on the same **network** trades with the others, no pipes.

The engine is central and works within a time budget per tick: many machines don't turn into lag,
they only share the throughput.

<br clear="all" />

## Where to start

1. Craft a router and read [Getting started](getting-started.md).
2. Learn about [networks](networks.md) and [filters](filters.md).
3. For big factories, use the <ItemLink id="wirelessautomate:linker" />, the
   <ItemLink id="wirelessautomate:configurator" /> and the <ItemLink id="wirelessautomate:network_tablet" />.
